About CV Projects {%- comment -%} 코드 저장소와 Notion 포트폴리오. 글자가 아니라 아이콘이라 이름이 없으므로 aria-label 을 준다 — 없으면 보조기술이 URL 을 읽는다. .btn 을 그대로 쓰는 이유는 옆의 글자 버튼들과 높이·여백이 저절로 맞기 때문이다. GitHub 는 테마가 동봉한 Font Awesome 4.7 의 웹폰트 '글자' 라 크기도 색도 저절로 따라온다. Notion 은 그 집합에 없어서 Simple Icons(CC0) 의 공식 마크를 인라인 SVG 로 직접 넣는다. 파일로 빼지 않은 이유는 fill 때문이다 — img 로 넣으면 색이 파일 안에 고정되어 다크에서 검은 마크가 되지만, 인라인이면 currentColor 로 옆의 글리프와 같은 색을 따라간다(_theme.scss). fill 을 속성으로도 박아 둔다. CSS 에 같은 값이 있는데도 중복해 두는 이유가 있다 — HTML 과 CSS 의 캐시 수명이 따로 논다(main.css 는 max-age=600). 배포 직후에는 '새 HTML + 옛 CSS' 를 받은 방문자가 생기고, 그때 .btn-glyph 규칙이 없어 SVG 가 기본값인 검정으로 칠해져 다크 카드에서 사라진다. 표현 속성은 어떤 CSS 규칙보다 우선순위가 낮으므로 스타일시트가 실리면 그쪽이 이기고, 안 실리면 이것이 받는다. {%- endcomment -%}
